# Next Stop 🚌

A premium, full-stack bus management and real-time tracking platform designed for modern transportation systems. Built with a sleek "Midnight Zinc" aesthetic, Next Stop offers a seamless experience for students, drivers, and administrators.

## ✨ Features

- **Real-time Tracking**: Live bus location tracking on an interactive map (powered by Leaflet).
- **QR Boarding System**: Professional QR code generation and scanning for student verification.
- **Automated Stop Alerts**: Smart notifications when the bus reaches your stop.
- **Admin Dashboard**: Comprehensive control panel for managing students, routes, and announcements.
- **Fee Management**: Integrated ledger for tracking tuition and transport fees.
- **Premium UI/UX**:
  - Glassmorphic design with smooth micro-animations (Framer Motion).
  - Editorial-style layouts inspired by modern streetwear brands.
  - Fully responsive across Mobile, Tablet, and Desktop.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS 4, Framer Motion, Phosphor Icons.
- **Backend**: Node.js, Express.
- **Database**: Supabase / PostgreSQL.
- **Real-time**: Socket.io / Supabase Realtime.
- **Deployment**: Vercel / Netlify.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- Supabase Project URL & Anon Key

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Rameesllo/next-stop.git
   cd next-stop
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Environment Setup**:
   Create a `.env` file in the `client` and `server` folders (see templates below).

4. **Run the application**:
   ```bash
   npm run dev
   ```
   This will start both the frontend and backend concurrently.

## 📱 Mobile Experience

The app is optimized for a PWA-like experience on mobile:
- **Slide-out Navigation**: Premium mobile drawer for quick access.
- **Scan-to-Board**: High-contrast QR scanner interface for drivers.
- **Adaptive Layout**: Optimized for one-handed use on all modern smartphones.
